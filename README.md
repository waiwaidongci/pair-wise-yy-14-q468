# hxyfront-62013 木结构榫卯测绘 · 勘测批次封样与替代构件放行台

源提示词编号：8

在古建筑木结构榫卯构件测绘页基础上扩展的批次封样、缺项补录、替代构件放行与补测重算工作台。

## 业务规则

- **唯一封样批次**：每栋建筑只保留一个封样批次；重复发起沿用首次封样，不另立新批、不覆盖首封测绘人。
- **开工锁定**：开工即锁定木种、构件编号与截面尺寸；缺含水率或病害记录只能通过「补录」补齐（已有值不可补录，需走补测）。
- **替代件整单放行**：仅贯穿裂缝构件可申请替代；备用件须木种、截面、榫型一致且未被其他批次占用。多行一单合并校验，任一行不合规则整单退回，不预留任何占用。
- **补测冻结重算**：发起补测即冻结原批关系边与修缮建议为只读旧版；仅允许改含水率、变形、病害，且须换人（与原测绘人不同）并经两次确认后按新值重算；旧版永久只读留档，可随时回看。
- **刷新一致**：状态持久化到 localStorage，刷新后构件清单、榫卯关系图、批次状态、版本快照同源一致。

## 代码结构（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `src/business/ledger.ts` | 构件台账：建筑 / 在役构件 / 备用件 / 病害记录、修缮建议派生、单栋关系边派生、种子数据 |
| `src/business/batchRules.ts` | 批次规则：封样沿用、开工锁定、缺项补录、替代放行整单校验、补测冻结 / 换人两次确认 / 重算（纯函数） |
| `src/business/pageState.ts` | 页面状态：reducer、store（useSyncExternalStore）、localStorage 持久化、操作通知 |

`src/business/selectBuildingView.ts` 为清单、关系图、批次控制台提供同一份「当前值 / 冻结旧版 / 历史版本」派生视图；`src/components/` 为各工作台面板（批次控制台、构件台账、关系图、放行台、补测台、病害标记图）。
